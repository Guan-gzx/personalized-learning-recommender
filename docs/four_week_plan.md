# 四周实施计划

| 周次 | 目标 | 可检查产物 |
|---|---|---|
| 第 1 周 | 调研 ASSISTments/EdNet 数据字段，确定知识点、前置关系和指标定义；完成系统方案与原型 | 选题报告、需求说明、方案 PPT |
| 第 2 周 | 完成 SQLite 表设计、知识图谱、数据清洗与时间序列模型原型 | 数据字典、ER 图、模型说明、阶段演示 |
| 第 3 周 | 完成推荐排序、Web 交互、导入器和离线评估；对接真实数据并调参 | 可运行系统、实验日志、论文初稿 |
| 第 4 周 | 完成消融实验、误差分析、论文修订、答辩彩排与部署说明 | 最终论文、答辩 PPT、源代码、验收演示 |

## 每周验收要点

第一周关注“问题是否定义清楚”；第二周关注“数据与模型是否可解释”；第三周关注“流程是否可运行且评价是否无泄漏”；第四周关注“材料是否与实际代码和实验边界一致”。
