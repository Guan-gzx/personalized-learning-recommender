# 数据与结论声明

## 数据边界

本项目随代码提供的 `data/demo_course.json` 和由其生成的 SQLite 交互记录，用于验证数据流、图神经网络邻域聚合、模型状态更新、推荐排序、页面交互和离线评估脚本。它们是确定性演示数据，不能被表述为 ASSISTments、EdNet 或真实班级的实验结果。交互表同时保留 `correct`、`duration_sec` 和 `answered_at`，以兼容公开教育数据中常见的对错、用时和时间字段。

## 可复现指标

运行 `python scripts/evaluate.py` 时，脚本把 demo_student 的最后 12 条交互作为按时间顺序的留出集，且推荐过程只能读取此前历史，避免未来信息泄漏。指标的含义如下：

- Precision@5：前五个推荐题中命中留出集中薄弱知识点的比例。
- Recall@5：留出集中薄弱知识点被前五个推荐覆盖的比例。
- NDCG@5：考虑题目排序位置的归一化折损累计增益。
- Model-estimated Knowledge Gain：在严格按时间切分的同一知识点上，以后测掌握度减前测掌握度计算；这是模型状态变化，不等同于真实教学因果效果。
- Learning Efficiency：弱知识点首次达到 0.75 掌握度时所需的推荐练习数；若留出序列中未达阈值，脚本明确报告“未达成”，不填造数值。

## 真实数据复现

经授权取得 ASSISTments 或 EdNet 数据后，先完成匿名化和字段映射，再将记录规范化为 `student_id,knowledge_id,question_id,correct,answered_at`。导入数据时应按学生维度、按时间顺序切分训练/验证/测试集；训练门控参数后，报告均值、标准差和对基线方法的显著性检验。不得将当前演示数值外推为真实学习效果。
